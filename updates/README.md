# Updates — Building FieldKit in Public

This directory contains the weekly LinkedIn posts that document the FieldKit journey — from the initial Mac Mini setup through every architectural decision, hard lesson, and shipped feature.

## Why build in public?

Building in public creates accountability, attracts collaborators, and documents the real journey for anyone who wants to follow the same path. These aren't polished retrospectives — they're honest, weekly snapshots of what's being built and why.

## Format

Each post is a markdown file named by publication date:

```
updates/
├── _template.md       # Copy this when writing a new post
├── YYYY-MM-DD.md      # One file per week
└── ...
```

## LinkedIn

Posts are published weekly on LinkedIn by [Sandeep Kesarkar](https://www.linkedin.com/in/sandeepkesarkar).

Each file includes the LinkedIn post URL at the bottom once published.

## Writing a New Post

1. Copy `_template.md` to a new file: `YYYY-MM-DD.md`
2. Fill in the template — the post should be ready to copy-paste to LinkedIn
3. Publish on LinkedIn
4. Add the post URL to the bottom of the file
5. Commit to `main`
